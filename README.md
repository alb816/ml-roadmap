- `notes/week-NN/`     - конспекты теории

## Правила работы
1. **numpy = транспорт, не решатель.** Нельзя, когда deliverable задачи - сама
   функция (np.mean/np.percentile в статистических задачах). Можно, когда numpy
   только перевозит данные (np.sort, np.convolve, np.linalg.solve).
2. **Правило 15 минут.** Застрял → 15 минут сам → только потом смотреть снаружи.
